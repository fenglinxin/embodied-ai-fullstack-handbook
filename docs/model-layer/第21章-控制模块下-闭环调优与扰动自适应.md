## 📌 开篇钩子

机械臂调试现场最常见的对话：
"它怎么抖？""增益问题。"
"它怎么飘？""前馈问题。"
"它怎么一碰就弹开？""……阻抗没调好。"

这些答案都对，但都没用——因为它们没有告诉你怎么**定位**问题。抖动可能是增益过高，也可能是结构谐振、编码器噪声、通信抖动甚至桌面共振；漂移可能是重力前馈不足，也可能是负载变了、标定歪了、温度变了。

本章把控制调试从"玄学猜增益"变成**方法论**：一张问题地图（抖/漂/振/碰各自往哪查）、一套系统辨识与自适应手段（负载变了怎么办）、以及控制链路低时延设计（延迟从哪里来、预算怎么分）。这是控制模块收官篇，也是"真机手感"的最后一公里。

## 二、问题地图：先分类，再动手

### 2.1 控制异常的四大类现象

| 现象 | 典型特征 | 大概率环节 | 低频误区 |
| --- | --- | --- | --- |
| 抖动/振荡 | 高频往复、嗡鸣、到位颤 | 增益、谐振、噪声、通信抖动 | 只降 P，实际是谐振/噪声 |
| 漂移/滞后 | 低速爬行、悬停下沉、跟不准 | 前馈、摩擦、负载、标定 | 只加 P，实际缺前馈 |
| 硬碰/弹开 | 接触力过大、回弹 | 控制模式（位置 vs 柔顺）、力阈值 | 调阻抗参数前没查模式 |
| 卡死/失控 | 偶发卡顿、跳变、安全停机 | 通信、限位、奇异、软件 bug | 当算法问题反复重训 |

> 💡 金句：**控制排障第一步不是调参，是分类——把问题归到正确的环节，再谈修。**

### 2.2 三步定位法

1. **记录现象**：误差曲线、速度曲线、力矩曲线、频谱（FFT）、时间戳；
2. **定位频段/环节**：抖动频率 = 结构谐振？控制频率的几分之一？通信抖动？用频谱和延迟日志分开；
3. **单变量实验**：一次只改一个变量（增益/前馈/滤波/频率），对比曲线决定去留。

## 三、分步实操

### 阶段 A：抖动的系统排查

#### 第 1 步：频谱分析定性质
- 采集到位后关节误差/力矩做 FFT；
- 特征判断：
  - 峰在**结构谐振频率**（机械臂固有频率）→ 陷波滤波器；
  - 峰接近**控制频率的 1/5–1/10** → 增益过高/相位裕量不足；
  - 宽带噪声 → 编码器噪声/通信抖动；
  - 低频往复 → 可能摩擦极限环或负载变化。

#### 第 2 步：对症下药
| 诊断 | 手段 |
| --- | --- |
| 结构谐振 | 陷波滤波（先扫频测准谐振峰） |
| 增益过高 | 降 P 或加 D（阻尼），保持带宽 |
| 传感器噪声 | 轻滤波（别把相位滤没） |
| 通信抖动 | 查总线负载/调度优先级/时间戳 |

#### 第 3 步：验证
- 同工况复测：抖动幅度降、轨迹误差不恶化、无新振荡；
- 全行程扫测（不同姿态谐振频率会变，留裕量）。

### 阶段 B：漂移与负载变化的自适应

#### 第 1 步：区分"缺前馈"与"标定错"
- 悬停漂移：重力前馈/负载参数问题；
- 低速爬行：摩擦补偿问题；
- 到点不准但动态好：运动学/TCP 标定问题（第 2 章）。

#### 第 2 步：负载辨识（自动化的关键）
1. 让机械臂沿固定小轨迹运动，记录力矩；
2. 用最小二乘/递推辨识**负载质量、质心**（或厂商自带的负载辨识功能）；
3. 辨识结果自动更新重力前馈与惯性补偿；
4. 换夹具/工件后触发重新辨识（门禁化，呼应第 2 章）。

#### 第 3 步：增益自适应（进阶）
- 负载重时降增益保稳定，负载轻时升增益保精度；
- 实现：查表（负载档位→增益组）或在线增益调度；
- 原则：**自适应改变的是"安全前提下的性能"，不是拿稳定性冒险**——始终留稳定裕量。

### 阶段 C：控制链路低时延设计

#### 第 1 步：画延迟预算表
端到端延迟 = 传感采集 → 状态估计 → 控制律 → 通信 → 执行器响应。每个环节标出典型值并设预算：

| 环节 | 典型量级（参考） | 优化手段 |
| --- | --- | --- |
| 传感采集 | 毫秒级 | 硬件触发/直接内存读取 |
| 状态估计/滤波 | 微秒~毫秒 | 减少重滤波、算法轻量化 |
| 控制律计算 | 微秒级 | 确定化调度、避免动态分配 |
| 通信 | 微秒~毫秒 | 实时总线、QoS、共享内存 |
| 执行器 | 毫秒级（含电流环） | 厂商级，选型时留预算 |

#### 第 2 步：消除"隐形延迟"
- 时间戳错位补偿（第 3 章）：控制用的状态要补偿到"指令生效时刻"；
- 丢包/重传策略：实时控制通道宁丢旧帧不发迟帧；
- 线程调度：控制线程实时优先级、锁内存、禁 GC（若用托管语言做控制要慎重）。

#### 第 3 步：延迟验收
- 测量端到端阶跃响应延迟（LED 事件→实际动作，第 3 章方法）；
- 目标：稳定、可预测（P95 不漂），比绝对小更重要——**抖动比延迟更伤控制**。

## 五、高频踩坑清单

| 现象 | 根因 | 排查 | 解决 |
| --- | --- | --- | --- |
| 一抖就降增益，越降越软 | 没先查谐振/噪声 | FFT 频谱 | 对症：陷波/滤波/通信 |
| 满载漂移空载好 | 负载参数没更新 | 悬停测试 | 负载辨识自动化 |
| 换工件后精度崩 | 换 TCP/负载没重标 | 查变更记录 | 变更门禁（第 2 章） |
| 控制偶尔"卡一下" | 线程调度被抢/GC | 看延迟日志 | 实时优先级+内存锁定 |
| 抖动消除但轨迹变慢 | 陷波/滤波引入相位延迟 | 看带宽 | 在稳定前提下提带宽 |
| 自适应越调越危险 | 在线增益无边界 | 看增益轨迹 | 上下限+安全判定 |
| 接触任务偶尔硬撞 | 模式切换时序问题 | 看模式切换点 | 切换前先减速/先预接触 |
| 延迟指标平均好、偶尔爆 | P95 超标 | 看分布 | 找偶发来源（日志/GC/总线） |

## 六、进阶优化

1. **学习式扰动补偿**：对可重复的扰动（负载轨迹相关、线缆弹力）用学习模型做前馈补偿，把"反馈硬扛"变成"前馈抵消"。
2. **数字孪生调参**：在仿真里用同一套控制器跑参数扫描（第 25 章起仿真层），把危险实验留在仿真，真机只验证优选参数。
3. **健康监控一体化**：长期监控各关节"力矩-误差"关系，漂移趋势提前预警（轴承磨损、负载偷偷变化），把控制排障变成预测性维护。
4. **与控制无关的忠告**：很多"控制问题"最后查到是机械问题（螺丝松、皮带跳齿、减速器背隙）——**先查机械，再调算法**。

---

## 七、本章 TOP3 核心总结

1. **排障先分类**：抖/漂/碰/卡各有主责环节，用频谱+误差曲线+单变量实验定位，不盲调增益。
2. **自适应是"辨识+调度"**：负载辨识自动更新前馈、按负载档调度增益，换夹具走门禁。
3. **低时延的目标是可预测**：延迟预算表逐环节优化，P95 稳定比平均值小更重要。

> 📌 记住这一句：**控制调优的终点不是"参数完美"，而是"问题可定位、变化可自适应、延迟可预测"。**
