# 具身智能工业级全栈工程落地手册

> 数据 → 模型 → 仿真 → 硬件 → 部署 → 产品化，六层全栈连载教程合集（公众号连载整理版）。
> 共 **1 篇开篇 + 52 章正文**，每章单篇独立、可直接收藏复用。

## 六层体系速览

| 层 | 章节 | 一句话 |
| --- | --- | --- |
| 数据层 | 第 1–12 章 | 机器人能力的"粮仓"：采集、清洗、数据集、质量与迭代闭环 |
| 模型层 | 第 13–24 章 | 机器人的"大脑"：感知、预测、规划、控制、VLA 与世界模型 |
| 仿真层 | 第 25–31 章 | 机器人的"训练场"：仿真选型、虚拟数据与 Sim2Real |
| 硬件层 | 第 32–37 章 | 机器人的"身体"：平台、底盘、臂手、传感与可靠性 |
| 部署层 | 第 38–44 章 | 机器人的"上岗"：推理、联调、稳定性与任务交付 |
| 产品产业层 | 第 45–52 章 | 机器人的"价值"：场景、量产、资本与产业趋势 |

## 推荐阅读路径

- **零基础**：开篇 → 第 1 章 → 第 13–15 章 → 仿真层 → 按兴趣展开
- **算法工程师**：数据层 → 第 22–24 章 → 规划控制
- **硬件/嵌入式**：第 32–37 章 → 数据接口 → 系统联调
- **产品/创业者**：产品产业层 → 按需回查工程章节

> 六篇"承重墙"建议精读：第 1 章、第 12 章、第 24 章、第 32 章、第 43 章、第 45 章。
