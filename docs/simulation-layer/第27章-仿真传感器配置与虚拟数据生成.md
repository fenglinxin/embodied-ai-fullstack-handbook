## 📌 开篇钩子

场景搭好了（第 26 章），训练开始前最后一道工序：**让仿真里的传感器像真机一样"不完美"**。

很多团队的虚拟数据"一眼假"：图像干净得像渲染宣传片、深度图没有噪声、力传感器没有零漂——模型在这么干净的数据上训练，一上真机就被真实的噪声、反光、飞点、模糊教做人。**真实传感器的不完美，恰恰是感知模型必须学会容忍的"世界底色"**。

本章解决：仿真传感器怎么配置才像真的、域随机化该随机什么、虚拟数据怎么批量生成并接入第 11 章的数据流水线、以及 Sim2Real 前怎么用"真机锚点"校验虚拟数据。

## 二、大白话原理：虚拟数据的关键是"分布像"，不是"单帧像"

### 2.1 传感器噪声的四类来源

| 类型 | 真机来源 | 仿真建模要点 |
| --- | --- | --- |
| 像素级噪声 | 传感器热噪声、增益 | 高斯噪声、光照随机 |
| 系统级误差 | 曝光、白平衡、畸变 | 快门/畸变模型、自动曝光模拟 |
| 深度/点云缺陷 | 飞点、孔洞、边缘混合 | 深度噪声+边缘毛刺+孔洞 |
| 时间误差 | 帧同步、延迟 | 时间戳抖动（第 3 章） |

### 2.2 域随机化 = 让模型"见过足够多的世界"

如果模型只在"一种光照+一种材质"里训练，它学到的规则会绑死这些外观。域随机化就是在**任务物理不变的前提下**随机化外观与次要物理参数（光照、纹理、颜色、摩擦、质量、相机位姿），逼模型学"不变的任务规律"。

> 💡 金句：**单帧像真的虚拟数据是艺术品；分布像真的虚拟数据才是训练数据。**

## 三、分步实操：配传感器 + 生成虚拟数据

### 第 1 步：相机配置对齐真机（先别加噪声）

1. 用真机相机的内参（FOV/分辨率/畸变）配置仿真相机；
2. 相机位姿 = 真机外参（第 2 章标定结果），保证视角一致；
3. 渲染一帧与真机同场景照片对比：构图、透视要对上——**这一步错了，后面全是白干**。

### 第 2 步：逐传感器加"噪声模型"

| 传感器 | 建议配置起点 | 验证方法 |
| --- | --- | --- |
| RGB | 亮度/对比度随机 ±20–30%，加轻噪声 | 直方图与真实图分布对比 |
| 深度 | 高斯噪声（随距离增大）、边缘飞点/孔洞 | 边缘误差、点云质量对比 |
| IMU | 偏置+白噪声（按规格） | 静态漂移曲线 |
| 力/力矩 | 零漂+高斯噪声+轻微温漂 | 静态读数分布 |
| 关节 | 编码器量化噪声、通信延迟抖动 | 跟踪误差对比 |

**原则**：噪声参数从真机短录（1 分钟静态+动态）统计出来，比"拍脑袋"可靠；先轻后重，用迁移评测收敛。

### 第 3 步：域随机化清单（按任务变量排序）

1. **必随机（低成本高收益）**：光照强度/色温/方向、相机位姿小扰动、物体颜色/纹理（同形状）、背景；
2. **按需随机**：摩擦/质量（±20–50%）、物体尺寸（±5–10%）、桌面纹理、干扰物数量；
3. **谨慎随机**：物理规律本身（重力方向/动作语义）——乱改等于出"假题"（第 10 章教训）；
4. 每个样本记录随机参数（种子），供失败分析与复现。

### 第 4 步：批量生成与录制

- 生成两种形态：
  - **回合式数据（用于 IL/VLA）**：脚本驱动"摆位→执行专家策略/程序化动作→录制 obs+action+success"（动作来源见第 28 章训练，此处可用脚本策略先产数据）；
  - **交互式数据（用于 RL）**：训练时实时渲染采样，不需要落盘；
- 用 GPU 并行批量跑（第 25 章选型的并行能力在此兑现）；
- 输出走第 3 章对齐后的统一 Schema（RLDS/WebDataset），时间戳/元数据齐全。

### 第 5 步：接入数据体系（域标签是红线）

- 每条仿真数据打 **source=sim + 场景版本 + 随机参数**；
- 按第 4/9 章跑清洗与质量抽检（渲染事故批次会产出"假数据"，同样要门禁）；
- 按第 10 章原则混合：真机锚点任务为主，仿真扩充变体；**仿真与真机分开统计评测**。

### 第 6 步：真机锚点校验（上线前必做）

1. 取 N 个"真机已能完成"的任务变体，仿真复现同样任务；
2. 同一策略在仿真与真机的成功率/行为分布对比；
3. 差距大 → 回到传感器噪声/域随机化/物理参数校准（第 28 章）；
4. **虚拟数据管线的验收指标 = 迁移率，不是生成量**。

## 四、核心参数详解

| 参数 | 建议起点 | 作用 | 备注 |
| --- | --- | --- | --- |
| RGB 亮度扰动 | ±20–30% | 光照鲁棒 | 别破坏身份 |
| 深度噪声 σ | 毫米~厘米级（按距离） | 几何鲁棒 | 用真机统计 |
| 摩擦随机范围 | ±20–50% | 接触鲁棒 | 按物体 |
| 物体尺寸随机 | ±5–10% | 尺寸泛化 | 别改到不可抓 |
| 相机位姿扰动 | 平移 cm 级/旋转 1–3° | 标定误差鲁棒 | 与真机标定精度呼应 |
| 仿真:真机比例 | 视任务（先 1:1 起调） | 混合策略 | 见第 10 章 |
| 迁移率红线 | 仿真与真机成功率差在可接受范围 | 上线闸门 | 任务自定 |

## 五、高频踩坑清单

| 现象 | 根因 | 排查 | 解决 |
| --- | --- | --- | --- |
| 虚拟数据训练真机全崩 | 噪声/物理不像 | 真机锚点对比 | 传感器噪声+物理校准 |
| 随机了个寂寞（不涨泛化） | 随机的是无关变量 | 看变量与失败关系 | 按任务关键变量随机 |
| 渲染批次有"穿模事故" | 无质量门禁 | 抽检 | 渲染后自动+人工抽检 |
| 仿真数据混入真机训练集 | 无域标签 | 查数据卡 | 域标签+分开评测 |
| 深度图"完美得像假的" | 没加噪声/飞点 | 与真机深度对比 | 加噪声+边缘缺陷 |
| 相机视角与真机不一致 | 外参没对齐 | 构图对比 | 用真机外参 |
| 数据量巨大但有效变体少 | 随机参数分布集中 | 看参数分布 | 拉宽分布/拉丁超立方采样 |
| 复现不了某条"神数据" | 未记录随机种子 | 查生成日志 | 记录种子与参数 |

## 六、进阶优化

1. **真机统计驱动噪声建模**：固定"1 分钟真机静态/动态采集"做噪声标定流程，每次换相机/传感器重标——把"像不像"变成统计指标。
2. **课程式域随机化**：训练早期随机范围小（易学），后期拉大（抗扰），比全程最大随机收敛更快更稳。
3. **对抗式"仿真难例"生成**：用上一轮模型的失败样本反推随机参数分布（哪里失败就在哪里加随机），虚拟数据也走第 12 章闭环。
4. **仿真数据进"数据资产地图"**：与真机数据同卡管理（版本/质量/授权），避免"仿真数据是后妈养的"各自散落。

---

## 七、本章 TOP3 核心总结

1. **传感器要"配得像真的"**：相机内参外参先对齐，再按真机统计加噪声（RGB/深度/IMU/力/关节五类）。
2. **域随机化要"随到关键变量"**：光照/外观/位姿/摩擦按任务排序随机，物理语义严禁乱改，参数全程记录。
3. **虚拟数据必须走数据体系**：域标签、质量门禁、真机锚点迁移评测——验收看迁移率，不看生成量。

> 📌 记住这一句：**仿真数据的使命是"让模型在虚拟世界里见过真机的刁难"——噪声与随机化，就是那些刁难的排练。**
