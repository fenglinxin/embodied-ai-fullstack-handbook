## 📌 开篇钩子

"零样本迁移"（sim-to-real zero-shot transfer）听起来性感：仿真里练好，真机直接跑，一条真机数据都不用采。但真实工程里它有一个残酷前提——**"零样本"指的是模型没看过真机数据，不是你的工程没做任何准备**。

那些"一次成功"的零样本 Demo，背后通常是：反复校准的仿真参数、覆盖极宽的域随机化、几十轮"仿真内最坏组合"压力测试，以及**首跑现场一整套降速限力预案**。把"零样本"理解成"零准备"，是仿真层翻车率最高的认知错误。

本章给仿真层收尾：什么任务适合零样本、首跑前 8 步清单、首跑现场怎么降风险、翻车了怎么排障、以及什么情况下必须放弃零样本转真机微调。

## 二、大白话原理：零样本为什么能/不能成功

### 2.1 零样本成功的三个条件

1. **动力学差距已被系统辨识压小**（第 28 章）；
2. **策略在域随机化区间内足够鲁棒**（训练时见过"最坏的真机"）；
3. **感知链路（相机/噪声/标定）与仿真假设一致**。

三者缺一，零样本就是赌。**零样本的实质是"把校准与鲁棒性都提前做完了"**——只是没做"真机数据微调"这一步而已。

### 2.2 哪些任务适合零样本

| 适合（差距可控） | 不适合（建议真机微调） |
| --- | --- |
| 规则几何任务（固定工位搬运） | 高精度接触（装配公差极小） |
| 接触简单（夹持、推方块） | 易碎/软性/变形物体 |
| 感知环境受控（固定光照） | 开放动态环境 |
| 有可靠仿真校准基础 | 首次进入的新任务/新材料 |

> 💡 金句：**零样本迁移考验的不是模型的聪明，而是仿真工程的前置投入。**

## 三、分步实操：真机首跑 8 步清单

### 第 0 步（前置）：迁移就绪度评审
对照第 28 章迁移矩阵：动力学/感知/执行三类差距均已量化且达标；域随机化边界压力测试通过；真机锚点评测通过。**有一条不达标，就不要叫"零样本"，按第 28 章补课。**

### 第 1 步：现场一致性检查（首跑前 1 天）
- 机器人模型版本/固件与仿真一致；
- 相机型号/内参/外参/安装位姿与仿真假设一致（第 2/27 章）；
- 工作台尺寸、物体（同款/同尺寸/同质量）、光照条件记录在案；
- 物体质量/摩擦与仿真设置一致（差异大先改物体或临时降难度）。

### 第 2 步：软件链路预检（不上电动作）
- 感知→策略→控制全链路跑通"仿真输入注入"（用录的真机数据喂策略，先验证接口）；
- 各节点延迟/频率符合预期；日志与安全监控上线；
- 急停、限位、限速、限力参数按"首跑保守档"设置（如速度 20–30%）。

### 第 3 步：空跑与低速干跑
1. 机器人**不带物体**空跑策略轨迹：检查路径是否合理、有无怪异抖动；
2. 带物体但**不执行关键动作**（只接近不抓）；
3. 每步都有人盯急停，异常即停。

### 第 4 步：最小变体首跑
- 选**最简单变体**（固定位置、最佳光照、无干扰）重复 10–20 次；
- 目标：先看"能不能成"，不看成功率；
- 记录每次失败的具体阶段（感知/接近/接触/执行）。

### 第 5 步：成功率与失败模式统计
- 简单变体跑 30–50 次，统计成功率与失败模式分布；
- 对比仿真同变体的分数——**差值就是"迁移差距"的现场实测**。

### 第 6 步：分级扩测
- 简单变体达标后，逐步放开：位置随机 → 光照变化 → 干扰物 → 满负荷；
- 每级都设"退出标准"：低于阈值回退上一级并分析，而不是硬闯。

### 第 7 步：首跑报告与决策
输出：各变体成功率、失败模式、与仿真分差、现场异常清单。决策：
- 差距小 → 扩大测试走向正式验证；
- 差距集中在某类 → 回仿真补域随机化/校准；
- 差距全面且大 → 放弃零样本，转真机微调（第 28 章第 5 步）。

## 四、首跑排障表（现场翻车对照）

| 现象 | 最可能原因 | 快速排查 | 动作 |
| --- | --- | --- | --- |
| 手伸向错误位置 | 标定/坐标系不一致 | 重投影检查 | 修外参/TCP，别调策略 |
| 动作"迟半拍" | 控制链路延迟超仿真假设 | 测端到端延迟 | 加动作块/降频/修实时性 |
| 抓取总滑落 | 摩擦/接触参数不符 | 对比物体质量摩擦 | 换物体/临时改夹爪/回仿真补随机 |
| 感知漏检/错检 | 光照/相机与仿真差距 | 现场图像 vs 仿真对比 | 加光照随机化/真机图微调感知 |
| 机器人犹豫/乱抖 | 策略没见过该观测分布 | 看置信度/熵 | 回仿真加该分布/降难度 |
| 偶发抽风一次 | 随机边界没覆盖 | 看触发上下文 | 补边界随机化，别当偶发忽略 |
| 第一次成功后面全失败 | 物体被第一次弄移位 | 检查场景复位 | 复位协议与物体固定 |
| 现场表现远差于仿真 | 某个前置假设失效 | 逐项对照 8 步清单 | 找到失效项，别盲目重训 |

## 六、高频踩坑清单

| 现象 | 根因 | 排查 | 解决 |
| --- | --- | --- | --- |
| 把"零样本"当"零准备" | 认知错误 | 就绪度评审 | 先过迁移矩阵再上真机 |
| 现场一次成功就宣布成功 | 样本量不足 | 看统计 | ≥30–50 次再看结论 |
| 失败了先重训而不是查现场 | 归因顺序反了 | 8 步清单逐项 | 先查标定/链路/一致性 |
| 物体/光照现场与仿真不同 | 没记录现场条件 | 对比记录 | 现场条件固定并记录 |
| 动作太慢没法用 | 保守档没放开 | 看分级测试 | 达标后逐级提速 |
| 传感器静默失效没人发现 | 无健康监控 | 看日志 | 感知健康监控（第 15 章） |
| 一翻车就放弃仿真路线 | 没有排障流程 | 失败模式归类 | 按排障表修仿真/适配 |
| 现场改了参数没同步仿真 | 版本脱节 | 查资产版本 | 真机-仿真参数同版本管理 |

## 七、进阶优化

1. **"影子部署"首跑**：真机运行时同时让仿真策略跑同一输入流，离线对比动作差异——无风险地暴露策略"看不懂真机"的部分。
2. **失败模式驱动仿真补课**：首跑失败模式（第 4 步）逐条翻译成仿真随机化/场景变体，补完再测，形成"真机考试→仿真补课"循环。
3. **自动化的现场一致性检查**：用标定板/标准物自动核对相机内外参与物体参数，把 8 步清单里的人工项变成开机自检。
4. **渐进自动化**：从人工值守 100% → 关键节点值守 → 无人试运行，每一步用数据（无事故运行时长）说话，不拍脑袋。

## 八、本章 TOP3 核心总结（仿真层收官）

1. **零样本 = 前置校准+域随机化+链路一致性的总验收**，不是"零准备"；就绪度评审不过就补课。
2. **首跑 8 步清单**：评审→现场一致性→链路预检→空跑→最小变体→统计→分级扩测→报告决策，全程保守档+急停值守。
3. **翻车先查现场与链路，再修仿真，最后才考虑转微调**——失败模式分类是决策的依据。

> 📌 记住这一句：**零样本迁移的成败，在真机通电之前就已经决定了。**
