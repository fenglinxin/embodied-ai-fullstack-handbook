## 📌 开篇钩子

"具身智能到底要学什么？"——这是本系列收到最多的提问。算法工程师会 Python 会 PyTorch，但不知道数据怎么采、模型怎么上真机；硬件工程师懂电机懂总线，但不知道算法要什么数据；创业者能讲清愿景，却被"你们和传统自动化有什么区别"问住。

这个行业不缺单点高手，缺的是**能把六层串起来的人**：数据、模型、仿真、硬件、部署、商业——任何一层断掉，产品都到不了客户手里。本系列 52 章，就是把这六层一层层讲透：每章单篇独立、可收藏复用，连起来就是一套《具身智能工业级全栈工程落地手册》。

本文是开篇：先给你一张全栈地图与学习路线，再告诉你不同背景该怎么读。

## 二、六层之间的依赖逻辑（为什么是这个顺序）

1. **数据决定模型上限**：没有领域数据，VLA 再强也学不会你的场景（第 1–12 章）；
2. **模型决定任务能力**：感知/规划/控制/VLA 各司其职（第 13–24 章）；
3. **仿真放大经验产量**：真机数据太贵，仿真负责批量变体与迁移（第 25–31 章）；
4. **硬件承载一切**：选型错、可靠性差，算法无处施展（第 32–37 章）；
5. **部署兑现价值**：实时性、稳定性、交付流程决定能不能上岗（第 38–44 章）；
6. **商业决定方向**：场景与产品定义反过来决定数据采什么、硬件配什么（第 45–52 章）。

**关键认知**：这不是单向流水线，而是闭环——商业反馈场景 → 场景决定数据 → 数据迭代模型 → 现场数据回流（第 12/28/43 章飞轮）。

## 三、学习路径：不同背景从哪读起

| 你的背景 | 推荐路径 | 为什么 |
| --- | --- | --- |
| 零基础/学生 | 第 1 章 → 第 13–15 章 → 第 25–31 章 → 按兴趣展开 | 先建立数据与感知认知，再进仿真低成本实践 |
| CV/NLP 算法工程师 | 第 1–12 章 + 第 22–24 章 → 第 17–21 章 | 先补"动作与数据"的课，再补规划控制 |
| 控制/机器人工程师 | 第 13–16 章 + 第 22 章 → 第 38–44 章 | 先补感知与学习型模型，再补部署交付 |
| 硬件/嵌入式工程师 | 第 32–37 章 + 第 1–3 章 → 第 40–44 章 | 先看整机与数据接口，再看系统联调 |
| 产品/创业者 | 第 45–52 章 → 第 7/32/43 章 → 按需回查 | 先定方向与算账，再深挖关键工程 |
| 投资人 | 第 45–52 章 + 第 50–51 章 | 建立"工程体系"尽调眼光 |

**通用建议**：每章都单篇独立，但**第 1、12、24、32、43、45 章是六层的"承重墙"**——时间有限时优先精读这六章，能最快建立全栈骨架。

## 四、52 章目录速览（六层全索引）

- **数据层（1–12）**：数据认知 → 采集 → 多模态对齐 → 清洗 → 去重均衡 → 脱敏 → 领域数据集 → 开源数据集 → 质量打分 → 增强 → 管道自动化 → 迭代闭环
- **模型层（13–24）**：感知(检测/深度/状态融合) → 预测 → 规划(路径/任务) → 控制(阻抗/灵巧/调优) → VLA → 世界模型 → 微调蒸馏轻量化
- **仿真层（25–31）**：选型 → 场景/数字孪生 → 传感器/虚拟数据 → Sim2Real → 训练加速 → 评测 → 零样本迁移
- **硬件层（32–37）**：整机架构 → 底盘 → 臂手 → 传感器同步 → 标定可靠性 → 上下位机
- **部署层（38–44）**：端侧推理 → 量化 → 低延时 → 闭环联调 → 排障 → 稳定性 → 任务交付
- **产品产业层（45–52）**：产品定义 → 工业 → 商用家用 → 特种 → 量产 → 头部复盘 → 投融资政策 → 趋势职业
