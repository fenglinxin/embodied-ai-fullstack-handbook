## 5. 参数白皮书

| 参数 | 默认 | 说明 |
| rank | 8(=d) | 容量-成本权衡 |
| bits | 8 | PTQ 位宽 |
| 蒸馏温度 | 1 | 软标签锐度 |
| 精度红线 | 掉点<=1-3% | 量化放行 |

## 6. Top5 踩坑

1. rank 太小表达力不够（L2 rank2/4 案例）。
2. 蒸馏只对齐输出不对齐任务：加任务蒸馏。
3. PTQ 校准集不含难例：掉点后先修校准集。
4. 量化掉点就上 QAT：先混合精度/敏感层分析。
5. 导出后行为漂移：导出后必跑黄金评测。
