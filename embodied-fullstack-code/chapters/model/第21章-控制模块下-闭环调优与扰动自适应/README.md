# 第21章《闭环调优与扰动自适应》代码落地包（控制模块收官）

> 配套文章：【具身智能全栈工程·第21章】抖、漂、撞、卡

## 1. 三层文件

| 文件 | 层 | 能力 |
| --- | --- | --- |
| demo_fft_diagnosis.py | L1 | 20-200Hz DFT 峰值定位谐振（47.4Hz 检出），区分谐振 vs 增益问题 |
| engineering_load_identification.py | L2 | 最小二乘负载辨识（m/摩擦/阻尼/偏置），结果可写回前馈 |
| advanced_gain_scheduling.py | L3 | 按负载档自适应增益：保持 wn/zeta 恒定，扰动响应一致 |

## 2. 环境：Python 3.9+ 零依赖（实测 3.13.3）

## 3. 快速运行
```bash
python demo_fft_diagnosis.py
python engineering_load_identification.py
python advanced_gain_scheduling.py
```

## 4. 标准运行结果（本机实测）

L1：信号主峰 47.4Hz（结构谐振预设 47.3Hz 检出）→ 建议陷波而非降增益

L2：辨识 m=2.002(真2.0)、摩擦=1.527(真1.5)、b=0.261(真0.3)、c=-0.007

L3：0.5/2/5kg 负载自动 Kp=50/200/500，扰动最大位移均为 0.036m（动态特性一致）

## 5. 参数白皮书

| 参数 | 默认 | 说明 |
| FFT 扫描带 | 20-200Hz | 机械臂谐振常见段 |
| wn/zeta | 10 / 1.0 | 增益调度保持动态一致 |
| 辨识模型 | tau=m*a+fric*sign(v)+b*v+c | 一轴简化 |
| 稳定裕量 | zeta>=0.7 | 自适应底线 |

## 6. Top5 踩坑

1. 一抖就降增益：先 FFT 查谐振（L1）。
2. 满载漂移空载好：负载没辨识（L2）。
3. 换夹具没重辨识：变更门禁触发 L2。
4. 自适应无限加增益：按 wn/zeta 约束（L3）。
5. 只看平均不看 P95 抖动：延迟/抖动看尾部分布。

## 7. 改造指南

- 真机 FFT：录 1-2s 到位误差，用 numpy fft 提速；
- 辨识激励：慢扫正弦/阶跃，多轴分别做；
- 调度表：把 L3 增益组写进控制器配置（按负载档索引）。
