# 第19章《轨迹跟踪与阻抗控制》代码落地包

> 配套文章：【具身智能全栈工程·第19章】规划给的是"愿望"，控制负责"兑现"

## 1. 三层文件

| 文件 | 层 | 能力 |
| --- | --- | --- |
| demo_pid_step.py | L1 | PID 阶跃响应对比（P 超调/PD 阻尼/PID 静差消除） |
| engineering_trajectory_tracking.py | L2 | smoothstep 轨迹 + PD 跟踪仿真，增益与误差量化关系 |
| advanced_admittance_contact.py | L3 | 导纳接触仿真：环境刚度+期望力，Ka 整定与过刚告警 |

## 2. 环境：Python 3.9+ 零依赖（实测 3.13.3）

## 3. 快速运行
```bash
python demo_pid_step.py
python engineering_trajectory_tracking.py
python advanced_admittance_contact.py
```

## 4. 标准运行结果（本机实测）

L1：P 超调 100%；PD 6.2% 且稳；PID 消除静差但 Ki 过大超调 27.4%

L2：Kp50→最大误差 0.061m；Kp200→0.014m；Kp800→0.003m

L3：
```text
Ka=200    峰值 113 N  (目标 5N：太软发飘)
Ka=800    峰值 28.6 N
Ka=3000   峰值 8.0 N  (接近目标)
Ka=10000  峰值 502 N  (离散带宽不足=过刚硬碰的教学案例)
```

## 5. 参数白皮书

| 参数 | 默认 | 说明 |
| Kp/Kd | 见 L2 三档 | 临界增益 50-70% 再配 D |
| Ki | 80 | 只在需要消静差时加 |
| 导纳 Ka | 3000（样例环境刚度5000） | 约0.6-3倍环境刚度 |
| 接触力目标 | 5N | 按工件 |

## 6. Top5 踩坑

1. 纯 P 超调/发散：加 D 阻尼。
2. Ki 过大超调：Ki 只消静差，别抢 Kp 活。
3. 导纳"感觉硬"：Ka 相对环境刚度太高（10000 案例）。
4. 接触任务用纯位置：会硬碰——改用导纳/阻抗。
5. 高速滞后加 P 无效：加前馈/带宽。

## 7. 改造指南

- 把 1D 仿真换成真机接口：u 接驱动器力矩/速度指令，x 接编码器回读；
- 导纳实现在位置控制臂上：外环力传感器→目标位置修正→内环位置执行；
- 调参纪律：一次只动一个参数，记录阶跃/跟踪曲线。

## 8. 进阶方向：重力前馈+摩擦补偿；阶段切换参数（接近刚/接触柔）；陷波滤谐振。
