# 评测工程《任务成功率 / 稳定性 / 泛化 / 回归》代码落地包

> 对应规范第(7)类"性能评测工程"：自动化评测、指标统计、任务成功率评估、版本可对比、迭代可量化。
> 衔接：仿真评测(第30章) → 真机任务评测(本包) → 发布门禁(第43章) → 验收交付(第44章)

## 1. 三层文件

| 文件 | 层 | 能力 |
| --- | --- | --- |
| demo_success_rate.py | L1 | 任务成功率评测最小闭环：分场景试次统计 + 放行线判定
| engineering_eval_runner.py | L2 | 评测运行器：Wilson 95% 置信区间 + P50/P95 + 多场景门禁 + 版本回归对比(JSON 落盘)
| advanced_generalization_matrix.py | L3 | 泛化矩阵(光照/遮挡/物品/距离退化单元) + 稳定性极差 + 多版本趋势决策

## 2. 环境：Python 3.10+ 零依赖，仅标准库（实测 3.13.3）；Windows 先执行 `set PYTHONIOENCODING=utf-8`

## 3. 快速运行
```bash
python demo_success_rate.py
# L2 两步：先存旧版本基线，再跑新版本对比
python engineering_eval_runner.py --version v1.4.3 --legacy --json-out base_v14.json
python engineering_eval_runner.py --version v1.5.0 --baseline base_v14.json
python advanced_generalization_matrix.py            # 三件套全量
python advanced_generalization_matrix.py --part gen # 只看泛化矩阵
```

## 4. 标准运行结果（本机实测）

### L1：三场景 10 试次，透明杯/动态行人 80% < 90% 放行线 → `评测未通过：禁止发布`

### L2 版本回归（v1.4.3 → v1.5.0）

| 场景 | v1.4.3 | v1.5.0 | 成功率差 | 结论 |
| --- | --- | --- | --- | --- |
| 抓取-透明杯 | 73.3% (CI95 [50.2,88.0] 量级) | 93.3% | +20.0pp | 无回归 |
| 避障-动态行人 | 73.3% | 93.3% | +20.0pp | 无回归 |
| 插拔-定位精度 | 90.0% | 100% | +10.0pp | 无回归 |

- v1.4.3 门禁：`未通过：存在未达标场景`；v1.5.0 门禁：`通过：全部场景达标`；
- 回归对比自动输出："无回归，版本可继续走发布流程(第43章)"；
- 指标带 Wilson CI95（小样本不骗人）、P50/P95 分位（抓取 P50 8.4s / 避障 P95 20.8s 等）。

### L3：泛化矩阵 + 稳定性 + 趋势（实测）

- 退化单元 2 个：遮挡/深遮挡(79%)、物品变体/半透明袋(84%) → "禁止直接量产，补真实场景数据后复测"；
- 补数据建议：光照最差强逆光 88%、遮挡最差深遮挡 79%、物品最差半透明袋 84%、距离最差 0.8m 94%；
- 稳定性：5 轮 [96,92,96,87,96] 极差 9pp > 8pp 判定线 → "先查环境条件一致性/任务判定标准，再谈发布"；
- 版本趋势 v1.3→v1.5：透明杯 84→92→96%、行人 82→86→93%、插拔 90→92→96%，无回退 → 放行。

## 5. 核心参数白皮书

| 参数 | 默认 | 最优工程值 | 适配场景 | 禁忌场景 |
| --- | --- | --- | --- | --- |
| 放行线 PASS_RATE | 90% | 按合同/客户期望(95%+) | 任务级验收 | 与验收标准不一致 |
| 试次数 | 10~15 | ≥30(置信区间才窄) | 正式评测 | 拿 3 次试错下结论 |
| 置信区间 | Wilson 95% | z=1.96 固定 | 小样本成功率 | 不报告 CI 只看点估 |
| P50/P95 | 分位统计 | P95≤节拍要求 | 延时/循环评测 | 只看均值被长尾骗 |
| 回归红线 | 成功率-5pp / P95+10% | 按噪声水平收紧 | 版本对比 | 无基线就谈回归 |
| 退化判定 | 比基准低 8pp | 按场景定 5~10pp | 泛化矩阵 | 与基准条件不一致时比 |
| 稳定性判定线 | 极差 8pp | 按成功率基线比例定 | 多轮复测 | 单轮下结论 |
| 趋势回退线 | 单版回退 3pp | 结合 CI 重叠判断 | 多版本迭代 | 两版噪声内比高低 |

## 6. Top5 高频踩坑（一键修复）

1. 只报成功率不报置信区间：n=10 时 80% 的 CI95 约 [49,95]，别拿点估吹牛——用 wilson_ci()。
2. 失败试次也把超长耗时算进节拍均值：循环指标用 P50/P95 而非 mean，长尾试次单列分析。
3. 基线/当前结构不一致导致回归误报：统一用本包 JSON 结构(场景结果数组)，compare() 按场景名映射。
4. 泛化评测只测标准条件：必须跑扰动矩阵，L3 自动抓"换条件就垮"单元并给补数据方向。
5. 成功率忽高忽低直接发版：先做 5 轮稳定性极差检查（判定线 8pp），排除环境/判定标准不一致。
