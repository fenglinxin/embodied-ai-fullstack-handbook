# 第44章《机器人任务落地调试完整流程》代码落地包

> 配套文章：【具身智能全栈工程·第44章】从能跑到能交付：验收门禁 + 证据链 + 量产关卡

## 1. 三层文件

| 文件 | 层 | 能力 |
| --- | --- | --- |
| demo_acceptance_gate.py | L1 | 验收门禁打勾：验收项 × 实测值 → PASS/FAIL → 禁止/允许交付
| engineering_acceptance_report.py | L2 | 验收报告生成器：PASS/EDGE(黄区)/FAIL 三态 + 证据链 + Markdown 交付物(含签署区)
| advanced_production_sop.py | L3 | 量产 SOP 关卡追踪：G0~G4 门禁、责任人、阻塞项/超期/豁免风险看板

## 2. 环境：Python 3.10+ 零依赖，仅标准库（实测 3.13.3）；Windows 先执行 `set PYTHONIOENCODING=utf-8`


## 4. 标准运行结果（本机实测）

### L1 验收门禁（默认演示数据含 1 项未达标）

- 任务成功率 0.92 < 95% → FAIL；其余三项 PASS；
- 门禁结论：`禁止交付：先修复再复测`；换成全达标 JSON 后输出 `验收通过，允许交付`。

### L2 验收报告（PASS 3 / EDGE 1 / FAIL 1）

- 任务成功率 93.0%：EDGE（黄区:距目标仅 2.1%，需复核）；
- 抓取位置误差 13.0mm > 10mm：FAIL（遗留阻塞项）；
- 节拍/安全事件/无故障运行：PASS；
- 门禁：驳回：修复后重测；自动落盘 `out/acceptance_report.md`（含明细表+黄区清单+签署区）。

### L3 量产关卡（G2 β小批实测）

- 任务 9 项、完成 5 项，就绪度 55.6%；
- 阻塞项未关 2 项（β小批 10 台产线试点、量产工艺文件发布），均已超期 2 天；
- 豁免项 1 项（α可靠性摸底，风险提示"须在下一关卡前补测，否则风险上移"）；
- 放行判定：`卡关`；G1 则 83.3% 就绪、无未关闭锁项 → 放行。

## 5. 核心参数白皮书

| 参数 | 默认 | 最优工程值 | 适配场景 | 禁忌场景 |
| --- | --- | --- | --- | --- |
| 任务成功率 | ≥95% | ≥98%（按合同条款） | 抓取/搬运验收 | 长尾新任务(先定任务集) |
| 循环节拍 | ≤60s | 节拍×0.8 留余量 | 产线节拍验收 | 手工慢速场景 |
| 位置误差 | ≤10mm | 按工艺精度要求定 | 装配/码垛 | 无测量基准时验收 |
| 安全事件数 | 0 | 0（一票否决） | 一切交付 | 无(禁止妥协) |
| 黄区宽度 EDGE_BAND | 5% | 按指标噪声水平调 | 临界数据复核 | 放宽成"擦边放行" |
| 证据要求 | 强制 | 录包+日志双证据 | 一切验收 | 口述验收 |
| 量产关卡 | G0→G4 | 关卡不可跳 | 量产导入 | 跳过安全/质量关 |
| 阻塞项超期 | 当天 | T-3 预警 | 关卡例会 | 超期静默 |

## 6. Top5 高频踩坑（一键修复）

1. 验收"差不多就行"：L1 门禁自动判定，FAIL 项进遗留清单，不人工豁免。
2. 数据漂亮没证据：L2 无证据一律 FAIL——测试视频/日志路径写进 evidence 字段。
3. 目标为 0 的指标除零：verdict() 先判 tg==0 分支（安全事件数不再误判黄区）。
4. 单位/百分比错乱：目标 0.95+unit="%" 自动按 95% 显示，实测 93.0%；避免手写两套。
5. 交付只验一次：量产用 L3 关卡制度，α 豁免项必须在 β 关前补测并留痕。

## 7. 二次开发改造指南
