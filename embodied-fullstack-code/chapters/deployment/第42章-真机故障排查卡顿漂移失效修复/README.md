### L2 分层排查（模拟证据命中 C1 通信丢包、A2 控制参数异常）

- 清单逐条给出证据 id/层/查法/是否命中；
- 命中加权后嫌疑层排序：通信(8) = 算法(8) > 环境/机械(0)，最高嫌疑层=通信；
- 处置建议自动给出：查总线配置与网线屏蔽：降波特率验证、换屏蔽线、加看门狗。

### L3 案例库统计

- 案例总数 5，未闭环 1（复发中的 C-004 正在整改）；
- 根因层分布：机械 40% > 通信/算法 20%；
- 复发追踪：末端漂移×机械 出现 2 次（C-001→C-004）= 系统性缺陷；
- 结论：同层同症状≥2次禁止只修个案，必须补预防措施。

## 5. 核心参数白皮书

| 参数 | 默认/示例 | 最优工程值 | 适配场景 | 禁忌场景 |
| --- | --- | --- | --- | --- |
| 现象四问字段 | 现象/何时/条件/复现 | 增加视频+录包编号 | 任何现场报障 | 空谈"偶尔不行" |
| 24V 母线电压 | ±5% 判定 | ±2% 监测告警 | 供电排查 | 单次测量下结论 |
| 证据成本 cost | 1~10 | 先查≤3 的项 | 现场快速收敛 | 直接拆机 |
| 证据解释力 severity | 1~10 | 机械类给高权重 | 加权排序 | 只看命中数 |
| 复发判定 | 同(症状,层)≥2 | ≥2 升级系统性缺陷 | 案例库复盘 | 两次内下结论 |
| 案例库字段 | id/日期/症状/层/根因/修复/预防/closed | 未闭环周更 | 量产复盘 | 只记不查 |

## 6. Top5 高频踩坑（一键修复）

1. 报障只说"卡了一下"：现象四问模板强制可测量字段，否则工单退回。
2. 一上来怀疑算法改参数：先跑 --hit 空证据看基线，按环境→通信→算法→机械顺序查，成本低优先。
3. 日志时区/单位混乱：现象记录与日志统一 UTC+同一单位（参考第41章回放检查）。
4. 修好个案不查复发：案例库按(症状,层)统计，≥2次必须补预防项并定整改人。
5. 真机复现不了就当没发生：录包+工况条件一起存档，L3 库中"未闭环"状态每周催办。

## 7. 二次开发改造指南

- L1：把四问接入报障网页/IM 机器人，缺字段自动驳回，形成企业知识库入口；
- L2：Check 表替换为真实命令（EtherCAT 抓包、ros2 topic hz、驱动诊断口），证据位改为日志/接口自动探测结果，可接第41章状态机做自动降级决策；
- L3：案例 JSON 存数据库，日期字段用于趋势分析；复发判断可扩展为"同根因不同症状"的跨案例关联；
- 与第37章（上下位机日志）、第43章（稳定性工程）打通：排障结论直接生成监控告警规则与回归用例。
