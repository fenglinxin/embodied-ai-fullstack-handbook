# 第43章《稳定性工程：监控/灰度/回滚/复盘》代码落地包

> 配套文章：【具身智能全栈工程·第43章】系统能跑不算赢，稳定跑 1000 小时才算

## 1. 三层文件

| 文件 | 层 | 能力 |
| --- | --- | --- |
| demo_health_beat.py | L1 | 健康度监控打点：滚动窗口失败率/P99 vs 红线，状态翻转防抖告警
| engineering_canary_release.py | L2 | 灰度发布执行器：5%→20%→50%→100% 放量，PASS/WATCH/ROLLBACK 三档判定自动回滚
| advanced_slo_postmortem.py | L3 | SLO 错误预算 + 燃烧率分档 + 故障复盘（MTTR/复发/整改闭环）

## 2. 环境：Python 3.10+ 零依赖，仅标准库（实测 3.13.3）；Windows 先执行 `set PYTHONIOENCODING=utf-8`

```bash
python demo_health_beat.py

python engineering_canary_release.py --scenario bad       # 劣化回滚
python engineering_canary_release.py --scenario flaky     # 抖动自愈
python advanced_slo_postmortem.py --day 22
```

## 4. 标准运行结果（本机实测）

### L1：5 分钟滚动窗口，命中第 8 分钟抖动
```json
{"监控窗口": "5分钟滚动", "告警条数": 1,
 "告警明细": [{"分钟": 8, "失败率%": 8.0, "P99ms": 610, "触发": "失败率越界"}],
 "结论": "命中抖动窗口8~10分钟，其余时段健康"}
```
（防抖机制：状态翻转才记一条，故障持续期间不刷屏）

### L2 三场景（放量节奏与判定）

| 场景 | 阶段过程 | 结论 |
| --- | --- | --- |
| healthy | 5%→20%→50%→100% 全 PASS | 全量发布完成 |
| bad | 5% 阶段 P99+317ms(硬) → ROLLBACK | 自动回滚到 v1.4.1，输出 ①流量切回旧版②停新版本号③留日志④复盘归因 |
| flaky | 5% 阶段 P99+80ms → WATCH(连续1)，20% 起转 PASS | 抖动自愈，发布不打断继续全量 |

### L3：SLO 99.9%，第 22 天检查（实测）

- 月错误预算 2592s，已消耗 975s，剩余 1617s，近 5 日消耗 420s，燃烧率 0.42 → 档位"正常"；
- 复盘：事故 4 起，网络类 2 起居首，平均 MTTR 1.9h；
- 复发事故 INC-004（网络链路抖动复发）→ 结论"复发=上次整改未闭环，禁止关单，挂长期改造项"。

## 5. 核心参数白皮书

| 参数 | 默认 | 最优工程值 | 适配场景 | 禁忌场景 |
| --- | --- | --- | --- | --- |
| 失败率红线 | 5% | 1~2% 预警告警分两档 | 抓取/搬运主链路 | 批量离线任务 |
| P99 红线 | 200ms | 按任务节拍定(≤1/3节拍) | 实时交互 | 长尾批处理 |
| 告警防抖 | 状态翻转记一条 | 加 1~3 分钟确认期 | 监控通道 | 应急期(需秒级) |
| 灰度阶段 | 5/20/50/100% | 每阶段≥5min 观察 | 算法/软件发布 | 安全关键补丁(先离线验证) |
| 软红线 | 失败率+2pp / P99+40ms | WATCH 连续2窗回滚 | 抖动容忍 | 强一致场景收紧 |
| 硬红线 | 失败率+5pp / P99+150ms | 立即回滚 | 一切在线发布 | 无(必须设) |
| SLO | 99.9% | 按客户合同倒推 | 月度预算 | 无 SLO 谈告警=空转 |
| 燃烧率档位 | 14.4/3.6/1.0 | P0 止血/P1 暂停发布/P2 关注 | 多窗口燃烧率 | 只看日均 |

## 6. Top5 高频踩坑（一键修复）

1. 指标只存不判：监控必须配"阈值+动作"，L1 演示三件套缺一不可。
2. 失败率分母为 0 报除零：请求数不足时窗口跳过或用 (ok+bad) 兜底为 1。
3. 抖动尖峰误触发回滚：用软/硬两级红线，单窗软越界只 WATCH 复核（见 flaky 场景），勿一刀切。
4. 回滚靠人肉点按钮：自动回滚动作清单提前写死并演练（L2 四步清单直接落地成脚本）。
5. 复盘关单不闭环：复发事故=整改未闭环，须挂长期改造项+责任人（L3 自动标记复发）。
